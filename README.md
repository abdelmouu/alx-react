# ALX React Project Portfolio

This repository contains a collection of projects and tasks completed as part of the ALX Software Engineering program. The projects cover the fundamentals of React, state management, and the modern React ecosystem.

## Modules & Concepts Covered

This portfolio is structured by modules, each demonstrating a specific set of skills:

* **[0x00-Webpack](https://github.com/abdelmouu/alx-react/tree/master/0x00-Webpack)**
    * Understanding and configuring Webpack for bundling assets, loaders, and plugins.

* **[0x01-react_intro](https://github.com/abdelmouu/alx-react/tree/master/0x01-react_intro)**
    * React fundamentals: creating basic components, understanding JSX, and rendering elements.

* **[0x02-react_props](https://github.com/abdelmouu/alx-react/tree/master/0x02-react_props)**
    * Passing data using `props`, `PropTypes` for type-checking, and creating reusable functional components.

* **[0x03-React_component](https://github.com/abdelmouu/alx-react/tree/master/0x03-React_component)**
    * Creating Class components, managing internal state, and understanding the component lifecycle.

* **[0x04-React_inline_styling](https://github.com/abdelmouu/alx-react/tree/master/0x04-React_inline_styling)**
    * Applying styles to components using inline styles and basic CSS-in-JS principles.

* **[0x05-react_state](https://github.com/abdelmouu/alx-react/tree/master/0x05-react_state)**
    * Advanced state management, using `setState` in class components and introducing React Hooks (`useState`, `useEffect`).

* **[0x06-React_Immutable](https://github.com/abdelmouu/alx-react/tree/master/0x06-React_Immutable)**
    * Introduction to Immutable.js to ensure state immutability, a core concept for predictable state management in React and Redux.

* **[0x08-react_redux_reducer_selector](https://github.com/abdelmouu/alx-react/tree/master/0x08-react_redux_reducer_selector)**
    * Fundamentals of Redux: creating reducers, understanding actions, and using selectors to retrieve data from the state.

* **[0x09-react_redux_connectors_and_providers](https://github.com/abdelmouu/alx-react/tree/master/0x09-react_redux_connectors_and_providers)**
    * Connecting React components to the Redux store using `Provider` and the `connect` high-order component.

## Core Technologies

* **React.js** (including Hooks and Class components)
* **Redux** (for state management)
* **JavaScript (ES6+)**
* **Webpack**
* **HTML5 & CSS3**
* **Jest** (for unit testing)
