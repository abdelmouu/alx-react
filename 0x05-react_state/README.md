# 0x05: React State

## Concepts

This module dives deeper into state management and introduces modern React Hooks.

## Learning Objectives

* Advanced state management in class components.
* Understanding how `setState` is asynchronous.
* Introduction to **React Hooks**:
    * Using the `useState` Hook to add state to functional components.
    * Using the `useEffect` Hook to handle side effects (equivalent to `componentDidMount` and other lifecycle methods).
* Introduction to the React Context API for passing state deeply.
