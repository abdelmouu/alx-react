# 0x03: React Components

## Concepts

This module explores the different types of components, focusing on state and lifecycle.

## Learning Objectives

* Understanding the difference between functional and class components.
* Creating **Class Components** using the `extends React.Component` syntax.
* Managing internal component state using `this.state` and `this.setState`.
* Understanding the basic component lifecycle (e.g., `componentDidMount`, `componentWillUnmount`).
* Handling events (like `onClick`) in a class component.
