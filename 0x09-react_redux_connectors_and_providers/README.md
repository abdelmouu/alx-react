# 0x09: Redux - Connectors & Providers

## Concepts

This module covers how to "connect" a React application to a Redux store.

## Learning Objectives

* Using the `<Provider>` component to make the Redux store available to the entire application.
* Using the `connect` High-Order Component (HOC) to link React components to the Redux store.
* Understanding `mapStateToProps`: linking store state to component `props`.
* Understanding `mapDispatchToProps`: linking Redux action creators to component `props`.
* Using Redux Thunk for handling asynchronous actions (like API calls).
