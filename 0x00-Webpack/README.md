# 0x00: Webpack Configuration

## Concepts

This module covers the fundamentals of using Webpack as a modern JavaScript module bundler.

## Learning Objectives

* Configuring Webpack for a basic project.
* Understanding `entry` and `output` points.
* Using loaders (e.g., `css-loader`, `style-loader`, `babel-loader`) to process different file types.
* Setting up `webpack.config.js`.
