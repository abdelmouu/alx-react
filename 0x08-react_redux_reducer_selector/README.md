# 0x08: Redux - Reducers & Selectors

## Concepts

This module covers the core concepts of Redux for global state management.

## Learning Objectives

* Understanding the Redux "single source of truth" (the store).
* Creating **Reducers**: pure functions that take the current state and an action, and return a new state.
* Normalizing state shape (e.in., using schemas).
* Creating **Selectors**: functions that extract specific pieces of data from the Redux store state.
* Using `combineReducers` to manage a complex store.
