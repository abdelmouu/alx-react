# 0x02: React Props

## Concepts

This module focuses on how React components communicate by passing data.

## Learning Objectives

* Understanding the concept of `props`.
* Passing data from a parent component to a child component.
* Using `PropTypes` to enforce type-checking on props for bug prevention.
* Building reusable, composable components.
* Working with lists and the `key` prop.
