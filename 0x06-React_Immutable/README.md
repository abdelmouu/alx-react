# 0x06: React & Immutable.js

## Concepts

This module introduces the concept of immutability, which is critical for predictable state management in React and Redux.

## Learning Objectives

* Understanding what "immutability" means and why it's important.
* Using the **Immutable.js** library to create immutable data structures like `Map` and `List`.
* Safely updating nested state without direct mutation (e.g., `setIn`, `merge`).
* Understanding how immutability helps React optimize rendering.
